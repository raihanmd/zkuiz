# Zkuiz

A practice platform for zero-knowledge arithmetic circuits.

The chosen stack is Next.js, Bun, and shadcn/ui. Components are designed for composition, with LeetCode as an interaction reference and a distinct visual identity.

Project setup and circuit-judge research are in progress. No application or judge has been implemented yet.

Read [CONTRIBUTING.md](CONTRIBUTING.md) for the test-first workflow, verifier gate, branch conventions, and local Codebase Memory setup. Agent-specific requirements live in [AGENTS.md](AGENTS.md).
