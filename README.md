# Zkuiz

Zkuiz is an open-source project for practicing zero-knowledge arithmetic circuit design and verification. The planned platform includes coding exercises and a browser playground.

## Status

Early development. The repository currently contains research and design notes. There is no runnable application or published package yet.

## Research

- [Circuit verification](docs/research/2026-10-29-zk-circuit-judge.md): testing, constraint analysis, and formal verification options.
- [Coding workspace](docs/research/2026-10-29-leetcode-workspace-rea.md): editor layout, test cases, and the distinction between running and submitting a solution.
- [Architecture notes](docs/research/2026-10-29-stack-and-component-contracts.md): application stack and component boundaries.
