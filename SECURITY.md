# Security policy

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/raihanmd/zkuiz/security/advisories/new) to report a security issue. Do not include exploit details, credentials, or private data in a public issue.

Include the affected commit, steps to reproduce the issue, and its potential impact. A minimal example is helpful; remove secrets and personal data before sending it.

## Supported versions

Zkuiz has no published releases. Please identify the commit you reviewed when submitting a report.
